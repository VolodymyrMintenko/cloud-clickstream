Three fixes in the cloud-clickstream project:

1. `_DailyUser` in web_clickstream.sqrl has no event timestamp after the GROUP BY, so its `ttl(30 days)` has nothing to age rows by and the 7-day self-join in `ActiveUsers` is an unbounded-state join. Give the table a recognized event time column so the 30-day retention actually expires rows and the trailing-7-day join is time-bounded, keeping DAU/WAU results unchanged.

2. All five query functions (`TopProjectsByUser`, `TopPages`, `PageTransitions`, `SessionJourney`, `ActiveUsers`) document their result columns but not their arguments. Extend each docstring to describe every parameter, including what `includeAdmins` does and that it defaults to false.

3. The `PageViewDedupTest` table test has no ORDER BY, so its snapshot row order is not pinned. Add a deterministic ORDER BY.

Keep the existing behavior and snapshots otherwise unchanged; re-run the tests and refresh only the snapshots these fixes legitimately change.
