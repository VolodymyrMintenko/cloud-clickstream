Make `org_id` and `org_name` nullable in the PageView payload.

The web app has pages that live outside any organization (/profile, /docs, /release-notes, /utilization and the admin area), so those two fields cannot always be supplied. Today they are NOT NULL in `connectors/pageview.sqrl` and the events would be rejected.

Change the schema and every connector so both columns accept null, keep every other column as it is, and make sure the query functions still behave: TopProjectsByUser groups by org_name but only reads events with a non-null project_id, which always carry an org. Add a fixture event with null org_id/org_name to the test data and re-run the tests, refreshing only the snapshots this legitimately changes. Update the README field table so both fields read as nullable.
