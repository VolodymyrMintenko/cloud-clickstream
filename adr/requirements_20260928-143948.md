Remove JWT authentication from the deployed API.

The clickstream data is internal product statistics with no user content in it, and requiring a token forces whoever reads it to paste a live access token into a browser, which we do not want. Drop the `vertx` `authKind`/`jwtAuth` block from `web_clickstream-prod-package.json` so the deployed API answers without a token, the way any other deployment on the platform does.

Leave `web_clickstream-local-package.json` and `web_clickstream-test-package.json` exactly as they are: their dummy JWT config and the test-runner Authorization headers are what the current tests run against. Re-run the tests to confirm nothing breaks, and update the README authentication section to say the deployed API is unauthenticated and that the write path is protected only by the deployment URL not being published.
